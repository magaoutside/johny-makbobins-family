## Задача

Вход — изображение, бокс, заявленный класс и признаки исходного детектора. Выход — один `score` для ранжирования боксов по ошибочности. Высокий score означает приоритет проверки. Скоры не заявляются как откалиброванные вероятности.

Классы: `person`, `nude_hands`, `cup`, `tray`. Целевая метрика — Average Precision. Используемый протокол разметки: совпадение по классу, IoU ≥ 0.60, взаимно-однозначное сопоставление с приоритетом максимального количества совпадений, затем их суммарного IoU. [Данные →](DATA.md)

## V52: геометрия и семантические прототипы

V52 строится поверх сохранённого V31. Базовый скор объединяет визуальные и геометрические свидетельства; V52 добавляет небольшой классификатор ошибки для `person`.

В выбранном CatBoost — **50 признаков**: 22 базовых геометрических/визуальных, 27 признаков семантических прототипов и категориальный `class_name`. Историческое название первой группы — `base23`; фактический состав проверяется по сохранённым моделям и manifest.

Прототипы — CLIP, DINOv2-B и DINOv2-L эмбеддинги GT-кропов обучающего дня. Для каждого класса берутся top-3/среднее косинусное сходство и margin к остальным классам. При построении признаков обучающих query исключаются прототипы в окрестности **±120 секунд**, чтобы снизить эффект почти совпадающих кадров.

| Параметр | Значение |
|:--|:--|
| Алгоритм | CatBoostClassifier |
| Depth / iterations | 2 / 250 |
| Learning rate / L2 | 0.03 / 10 |
| Seeds | 23, 24, 25 |
| Fit days | 25 и 26 октября 2026 |
| Количество моделей | 6 |

OOF-прогноз использует три seed, обученных только на противоположном дне. Test-прогноз усредняет все шесть моделей. Для `person`:

```text
V52 = (V31 + 0.2 × mean_CatBoost) / 1.2
```

Для остальных классов V52 сохраняет V31. `id`, день, кадр и целевая метка не передаются CatBoost как признаки. [Исходное обучение](../research/rascar_v52/train.py) · [Manifest моделей](../solutions/v52/manifest.json).

## V57: поправки по независимым экспертам

Пусть `b = V52`, `p_full` — средний прогноз SAM2/TabICL-экспертов по контексту изображения, `p_crop` — средний прогноз по кропу. Для `person` и `cup`:

```text
s = b + clip(0.2 × (p_full − b), 0, 0.1)
      + clip(0.2 × (p_crop − b), −0.1, 0)
```

Контекстный эксперт может повысить подозрительность, кроповый — понизить. Это направленная, ограниченная коррекция, а не свободная замена сильного baseline.

Для `nude_hands` используется исходный anchor TabICL с адаптацией class prior по неразмеченным прогнозам соответствующего дня. Источник prior — метки fit-day с Laplace-сглаживанием; EM использует strength 10 и 100 итераций. Готовая поправка:

```text
s_hands = b + clip(0.2 × (p_anchor_adapted − b), −0.1, 0.1)
```

Адаптация не использует скрытые test-метки. Её transductive-характер описан в [валидации](VALIDATION.md). Полный исходный расчёт — [`correct_outliers.py`](../research/rascar_v56/correct_outliers.py).

## V58: пространственная голова и RGB flip TTA

Основное новое визуальное свидетельство — независимая оценка геометрии `cup` из DINOv2-B.

```text
RGB context crop, 448 × 448
  → frozen DINOv2-B
  → 768 × 32 × 32 patch features
  → channel normalization × sqrt(768)
  → Conv 1×1: 768 → 64 → GELU
  → Conv 3×3: 64 → 64 → GELU → Dropout2d(0.1)
  → Conv 1×1: 64 → 4
  → sigmoid occupancy maps
```

Обучение: 450 шагов AdamW, learning rate 0.0005, weight decay 0.03, batch 8. BCE взвешена как `1 + 3 × target`; градиент ограничен нормой 5. Кадры балансируются через обратную частоту кропов. Targets — occupancy по размеченным прямоугольникам, а не пиксельные instance-маски.

При обучении действительно отражается RGB-изображение, затем повторно извлекаются DINO-признаки. На инференсе оригинальная и отражённая версии усредняются 50:50 после обратного отражения карты. Карты трёх seed **3101, 3102, 3103** усредняются **до** извлечения компонент и вычисления геометрии.

### Замена dense-компоненты `cup`

Из overlap/IoU получается целевой скор:

```text
dense_target = clip((0.85 − overlap) / 0.5, 0, 1)
new_dense    = V22 + 0.25 × (dense_target − V22)
```

OOF использует только голову противоположного дня. На test оба fit-day эксперта должны иметь геометрию и согласиться по направлению поправки относительно V22. Берётся консервативная из двух оценок.

Для поддержанных `cup`-боксов:

```text
s_cup = s_V57 + new_dense − V31
```

Если новая геометрия отсутствует или эксперты противоречат друг другу, сохраняется прежний вклад V57. Такой guard изменил 8 test-прогнозов относительно варианта без guard; на OOF эти варианты совпали. Он выбран как правило сохранения предыдущего свидетельства, до чтения визуальных test-флагов.

### Калибровка `tray` и общий предел

```text
s_tray = sigmoid(logit(clip(V52, 0.0001, 0.9999)) − 0.6)
s      = clip(s, 0, 1)
V58    = V52 + clip(s − V52, −0.15, 0.15)
```

Сдвиг `tray` сохраняет порядок внутри класса, но меняет его положение относительно других классов. Проверять только AP по отдельным классам поэтому недостаточно.
