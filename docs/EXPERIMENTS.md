## V52

Исследовались геометрия, frozen-модельные признаки, CLIP/DINO-прототипы, пиксельная статистика, PCA эмбеддингов, вложенные dense-прогнозы, признаки границ, аугментации боксов и несколько способов смешивания. Основные классификаторы — CatBoost глубины 2/4 и Logistic Regression.

Финал — компактный CatBoost depth 2 по базовой геометрии и семантическим прототипам, с исключением соседних train-прототипов ±120 секунд. Три seed усредняются; поправка применяется только к `person` с alpha 0.2.

## V56 и V57

V56 A40 усиливал вклад TabICL для рук и получил Public **0.96285**, ниже V52 **0.96300**. Это показало, что локальный выигрыш не гарантирует роста на leaderboard.

V57 добавил направленные ограниченные поправки SAM2/TabICL, адаптацию prior для рук и калибровку tray. OOF вырос до **0.992147**. Отдельной отправки V57 не было; он стал основой финального поиска.

## Финальный поиск V58

| Направление | Объём | Вывод для финала |
|:--|:--|:--|
| Новые TabICL-эксперты | 4 семейства, 3 seed, 2 fit-day; 60 fits с учётом моделей по классам | Проверены; не заменили выбранную V57-компоненту |
| Jackknife по кадрам | 3 семейства × 35 исключаемых query-кадров = 105 fits | Mean/median/trimmed и prior-коррекции не выиграли финальный вариант |
| Frozen DINO-B/L + nonlinear heads | 2 backbone × 2 головы × 3 seed × 2 дня = 24 головы | DINO-B spatial вошёл для `cup` |
| Fine-tuning DINO-S/B | 2 pilot + 12 обучений; checkpoint на frozen150/tuned350/tuned750 | Не превзошёл выбранную spatial+TTA ветку |
| Реальный RGB flip TTA | 3 seed × 2 дня; original/flip смешивание | Усреднение 50:50 вошло в V58 |
| Ограничения и калибровка | Guard геометрии, class scope, tray shift, cap | Guard + tray logit −0.6 + cap ±0.15 |
| Seed / bootstrap / composition stress | 3 seed, 2000 bootstrap, 486 сценариев | Дополнительная проверка фиксированного кандидата |

Финальная таблица содержит **363 записи / 360 уникальных пар OOF+test**. Строки с разными весами одного эксперта — не независимые эксперименты. [Таблица кандидатов](../reports/v58/candidates.csv).

## Почему выбран именно этот вариант

- Лучший pooled development OOF среди проверенных кандидатов.
- Средний ансамбль не ухудшает ни один день относительно V57.
- Все три seed улучшают pooled AP относительно V57 и оба дня относительно V52.
- Если новое свидетельство `cup` отсутствует или противоречиво, сохраняется старое.
- Абсолютная поправка ограничена ±0.15 относительно V52.
- Кандидат зафиксирован до чтения визуальных test-флагов.

Финальный Public: **0.97564**, или **+0.01264 AP к V52**. Это наблюдаемый результат конкретного сабмита; вклад каждого изменения отдельно на Public не измерялся.
